# [ARCHIVED] План впровадження AI-обробки та покращеного експорту законів

Цей документ описує етапи розширення існуючого парсера для виконання нових вимог: генерація коротких описів статей, виділення суб'єктів (Actors/Регуляторів) та експорт даних для Google Sheets.

## 1. Модернізація бази даних (Models)
**Файл:** `src/models/Element.js`
* Додати поле `shortDescription: String` до моделі `Element` для зберігання стислого змісту статті.
* Поле `subjects: [String]` вже існує і буде використовуватися для зберігання "Регуляторів/Actors".

## 2. Створення сервісу ШІ (AI Service)
**Файл:** `src/services/aiService.js`
* Реалізувати функцію `processArticleContent(articleTitle, articleText)`, яка:
    * Використовує вказаний у тасці промт.
    * Взаємодіє з OpenAI API (або локальним Ollama).
    * Повертає структурований JSON з акторами, коротким описом та категорією (Розділ).

## 3. Скрипт обробки даних (Enrichment Script)
**Файл:** `scripts/enrichLawData.js`
* Новий скрипт, який:
    1. Бере вже розпарсений закон з бази.
    2. Для кожної статті (тип `article`) збирає повний текст (включаючи параграфи).
    3. Відправляє дані в `aiService`.
    4. Оновлює відповідний документ в MongoDB, додаючи `shortDescription` та `subjects`.
* **Перевага:** Це не ламає початковий парсинг. Якщо AI помилиться, ми можемо запустити обробку повторно без перепарсингу HTML.

## 4. Скрипт експорту (Export Script)
**Файл:** `scripts/exportToSheets.js`
* Скрипт для генерації CSV або JSON файлів, структурованих під Google Sheets:
    * **Лист 1 (Short Description):** Заголовок закону, Номер статті, Короткий опис.
    * **Лист 2 (Full Description):** Заголовок закону, Назва розділу, Номер статті, Повний текст, Регулятор (Actors).

## 5. Промт для AI (збережений у коді)
```json
{
  "system": "Ти — експерт з українського законодавства. Твоє завдання — структурувати текст статті.",
  "prompt_template": "Ти отримаєш нормативно-правовий документ...\nПоверни інформацію в вигляді JSON: {\"name\": \"...\", \"text\": \"...\", \"actors\": [...], \"Chapter\": \"...\", \"short_description\": \"...\"}"
}
```

## Черговість виконання:
1. **Етап 1:** Додавання `shortDescription` в схему Mongoose.
2. **Етап 2:** Створення `aiService.js` з базовим моком (щоб протестувати логіку без витрат токенів).
3. **Етап 3:** Написання `exportToSheets.js` для перевірки, що формат виводу відповідає вашим Google-таблицям.
4. **Етап 4:** Підключення реального OpenAI/Ollama для фінальної обробки.
